🚀 Crypto Time Series Analysis Project

📊 Overview

This project analyzes and predicts Bitcoin prices using time-series forecasting and machine learning models.

---

🛠️ Technologies Used

- Python
- Streamlit
- Pandas, NumPy
- Matplotlib
- ARIMA
- Prophet
- LSTM (Deep Learning)

---

📈 Features

- 📊 Interactive Streamlit Dashboard
- 📉 Price trend visualization
- 🔮 Forecasting using multiple models
- 📊 Model comparison (RMSE)
- 📅 Time-series analysis

---

🤖 Models Implemented

- ARIMA
- Facebook Prophet
- LSTM Neural Network

---

📂 Project Structure

- app.py → Streamlit dashboard
- models/ → ML models
- data/ → Dataset
- evaluation.py → Model comparison
- requirements.txt → Dependencies

---

▶️ How to Run

1. Install dependencies:

pip install -r requirements.txt

2. Run the app:

streamlit run app.py
